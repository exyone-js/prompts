# 公众号爆款文案

## 目标
生成适合微信公众号传播的爆款文章，包含标题、正文和互动引导。

## 示例 Prompt

```
请帮我写一篇公众号文章。

## 主题
"拖延症的本质不是懒，而是完美主义"

## 文章要求
1. 标题：准备 3 个备选标题，要求有数字、有冲突感、能激发好奇心
2. 开头：用场景化描述引入，让读者产生"这说的就是我"的感觉
3. 正文结构：
   - 反驳常见误区（拖延 = 懒）
   - 给出核心观点（完美主义导致恐惧失败）
   - 提供 3 个可操作的改善方法
   - 每个方法配一个真实案例或比喻
4. 结尾：金句收尾 + 互动引导（提问让读者留言）
5. 全文字数：1500-2000 字
6. 语调：真诚、不说教、适当口语化
```

## 技巧
- 标题用数字和冲突感吸引点击
- 开头使用"场景代入法"留住读者
- 观点 + 方法 + 案例的结构最受欢迎
- 结尾用提问代替求赞，互动率更高
