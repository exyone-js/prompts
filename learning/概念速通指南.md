# 概念速通指南

## 目标
快速理解一个陌生领域或技术概念，适合入门学习场景。

## 示例 Prompt

```
请用通俗易懂的方式帮我理解 "Kubernetes"。

## 要求
1. 用类比开头——把它比作一个日常生活中容易理解的事物
2. 用 3 句话以内说清楚它解决的核心问题
3. 列出 5 个最核心的概念，每个用一句话解释
4. 用一个具体的使用场景串联起这些概念，展示它们如何协同工作
5. 推荐 1-2 个适合初学者的实践资源

## 我的背景
有 3 年后端开发经验，熟悉 Docker 基本使用，但对容器编排没有实际经验。
```

## 技巧
- 说明你的背景知识水平
- 要求用类比帮助理解
- 限定核心概念数量，避免信息过载
- 要求场景串联比单独解释更有效
