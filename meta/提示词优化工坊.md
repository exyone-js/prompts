# 提示词优化工坊

## 目标
让 AI 帮你改进和优化已有的 prompt，提升输出质量和稳定性。

## 示例 Prompt

```
请帮我优化下面这条 prompt，目标是提高输出质量和稳定性。

## 原始 Prompt
"帮我写一篇关于人工智能的文章。"

## 优化要求
1. 分析原始 prompt 的问题（至少指出 3 个不足之处）
2. 给出优化后的完整 prompt 版本
3. 解释每项改进的原因和预期效果
4. 如果适用，提供 2-3 个不同侧重点的变体版本

## 场景补充
- 目标读者：C 端普通用户，非技术背景
- 用途：公众号科普文章，字数 2000 字左右
- 风格要求：轻松有趣，多用比喻，避免术语堆砌
```

## 技巧
- 原始 prompt + 场景补充比单纯让 AI 优化更有效
- 要求 AI 分析问题可以帮助你理解 prompt 设计原则
- 多个变体版本可以拓宽思路
- 适合用来打磨重要且反复使用的 prompt
